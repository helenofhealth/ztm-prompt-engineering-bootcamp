# Snake Game

A browser-based Snake game built with HTML, CSS, and JavaScript as part of the Zero To Mastery Prompt Engineering Bootcamp.

## Status

In development.

## Features

- Classic Snake gameplay
- Keyboard controls
- Score tracking
- Snake growth
- Collision detection
- Game-over state
- Pause/resume functionality
- Restart functionality
- Quit functionality

## AI-Assisted Development

This project was developed iteratively with AI assistance.

The development process includes:

- Original build prompt
- Feature requests
- Debugging prompts
- AI-generated defects
- Corrections and reasoning
- Testing and iteration

## Technologies

- HTML
- CSS
- JavaScript
- HTML Canvas

## Running the Game

Open the HTML file in a modern web browser.
