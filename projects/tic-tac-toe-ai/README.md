# Tic-Tac-Toe AI

An AI-powered Tic-Tac-Toe game built as part of the Zero To Mastery Prompt Engineering Bootcamp.

## Status

In development.

## Features

- Human vs AI gameplay
- Game-state management
- Win detection
- Draw detection
- Invalid-move handling
- Game reset
- Score tracking
- AI opponent
- Minimax decision-making

## AI Opponent

The AI opponent uses game-state evaluation and decision logic to select moves.

The project documents the AI design, game rules, decision logic, testing, and debugging process.

## Testing

Testing includes:

- Invalid moves
- Full board/draw scenarios
- Winning positions
- Losing positions
- AI decision-making
- Edge cases

## Technologies

- HTML
- CSS
- JavaScript
